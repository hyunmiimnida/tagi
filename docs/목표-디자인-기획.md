# 캠퍼스모아 2028 — 발견한 기회를 내 경험으로

> **비전: 대구·경북·부산 대학생이 자신에게 맞는 기회를 발견하고, 준비와 지원을 끝까지 이어 가도록 돕는 캠퍼스 생활 동반자.**

## 1. 현재 서비스와 목표 사용자

### 현재 서비스에서 이어 갈 기반

`CLAUDE.md`, `app/`, `components/`를 기준으로 현재 캠퍼스모아는 학교 공지·취업·대외활동을 같은 형식으로 정리하는 모바일 웹이다. 학교·대상·태그 검색, 관심 표시, 개인 캘린더, 원문 신청 연결이 중심이다.

이미 학교·학년·관심 분야에 따른 기본 맞춤 기능, 관심 공고의 하루 전 마감 알림, 반복 프로그램의 지난 공고와 후기 댓글, 공유와 캘린더 내보내기도 있다. 회색 배경과 흰 카드, Pretendard, 파란 강조색, 크림색 참새 아이콘, 자동 다크 모드가 현재 시각적 기반이다.

**목표 모습은 ‘공고를 잘 모아 주는 서비스’에서 ‘나에게 맞는 공고를 찾고 실제 지원을 완료하는 서비스’로 발전하는 것이다.**

## 2. 지금 대비 달라질 핵심 기능 8개

| 기능 | 현재 | 1~2년 뒤 목표 경험 |
|---|---|---|
| **1. 추천 이유가 보이는 개인화 피드** | 학교와 관심 태그에 맞는 공고를 별도 목록으로 표시 | 학교·학년·관심 직무·활동 목적·참여 가능 시간을 함께 반영한다. 카드에 “경영학 전공 · 데이터 직무 관심으로 추천”을 표시하고, 사용자가 추천 이유를 수정하거나 관심 없는 공고를 숨길 수 있다. |
| **2. 생활 조건까지 반영하는 탐색** | 학교·대상·분야·활동 형태 등의 태그 필터 | 활동 지역, 온라인 여부, 요일, 주당 시간, 비용, 초보자 참여 여부를 추가한다. 지원 조건은 **조건 일치 / 확인 필요 / 조건 불일치**로 구분한다. 정보가 없는 항목은 ‘확인 필요’에 남긴다. |
| **3. 공고별 지원 준비 체크리스트** | 일정과 모집 대상을 읽고 원문에서 신청 | 공식 준비물과 사용자가 추가한 할 일을 한곳에 모은다. “이력서 PDF 준비”, “자기소개서 700자 작성”에 개인 준비 기한을 붙이고 상세·홈·일정에서 같은 진행 상태를 보여 준다. |
| **4. 지원 단계와 결과 관리** | 관심 공고의 모집·활동 일정을 캘린더로 확인 | **관심 → 준비 중 → 제출 완료 → 결과 기록**으로 관리한다. 공고 마감과 개인 준비 기한을 구분하고, 활동 일정이 겹치면 알려 준다. 외부 사이트에서 제출한 결과는 사용자가 직접 확인해 기록한다. |
| **5. 준비 상황을 반영하는 알림** | 관심 공고의 마감 하루 전 오전 9시 알림 | 3일 전·하루 전·당일 알림을 선택한다. 미완료 준비물, 개인 준비 기한, 원문에서 확인한 마감 변경도 알려 준다. 제출 완료한 공고의 지원 마감 알림은 종료한다. |
| **6. 회차별로 정리된 합격·참여 후기** | 반복 프로그램에 후기 댓글 작성 | 회차, 지원 결과, 준비 기간, 서류 팁, 활동 부담을 구조화한다. 참여 인증 여부와 작성자가 입력한 합격 여부를 구분하고, 이번 공고의 준비 목록으로 팁을 가져올 수 있다. |
| **7. 친구와 함께 준비하기** | 공고 링크 공유 | 초대 링크로 공고와 공통 준비 목록을 공유한다. 팀 공모전은 역할과 담당자를 정하고, 개인 지원은 각자의 제출 여부를 선택적으로 공유한다. 개인 서류와 비공개 메모는 본인만 본다. |
| **8. 반복 프로그램의 다음 회차 구독** | 지난 공고를 보고 모집 시기를 가늠 | 마감된 프로그램에서도 “다음 모집 알림 받기”를 누를 수 있다. “지난 2회는 10월에 모집했어요”처럼 관찰된 이력을 보여 주고, 새 회차가 실제 게시되면 알려 준다. |

   - `주 4시간 · 교통비 개인 부담`
   - `도움됐어요 21 · 댓글 3`

7. **스크롤 아래**
   - `지금 준비 중인 학생의 질문`
   - 예시: `데이터 실무 프로젝트, 비전공자도 면접에서 코딩을 물어보나요?`
   - `답변 4개 · 2시간 전`

8. **고정 글쓰기 버튼**
   - 하단 탭 위 오른쪽: 펜 아이콘 + `후기 쓰기`
   - 하단 탭에서 `후기` 활성화.

**첫 화면에 보일 범위:** 소개, 필터, 첫 번째 후기 전체와 두 번째 카드 상단.

#### 강조할 인터랙션

- 연결 공고를 누르면 현재 모집 중인 회차로 이동한다.
- 후기를 열면 `회차 / 준비 과정 / 서류·면접 / 실제 활동 / 추천하는 사람` 순서로 읽는다.
- 후기의 준비 팁 옆 `내 준비 목록에 추가`를 누르면 **개인이 추가한 할 일**로 저장한다.
- `참여 인증` 배지를 누르면 인증의 의미를 설명한다. 제출한 인증 자료는 공개하지 않는다.
- 합격 여부는 작성자 입력과 별도로 표시한다.
- 신고·사용자 숨기기는 카드 더보기에서 제공한다.

### 화면 7. 프로필 / 알림 설정

**화면 목적:** 추천에 쓰는 내 정보와 받을 알림을 이해하고 직접 조절한다.

**목업 상태:** 로그인한 김서연. 지원 마감 알림이 현재 기기에서 활성화되어 있다.

#### 위 → 아래 구성

1. **상단 헤더**
   - 제목: **`내 정보`**
   - 오른쪽: 더보기

2. **프로필 카드 · 약 108px**
   - 크림색 원형 아바타 56px, 가운데 참새
   - 닉네임: **`서연참새`**
   - 정보: `경북대학교 · 경영학부 · 3학년`
   - 작은 문구: `카카오로 로그인`
   - 오른쪽: `수정`

3. **활동 요약 · 약 72px**
   - `저장 12`
   - `준비 중 3`
   - `제출 완료 2`
   - `내 후기 2`
   - 숫자를 누르면 해당 목록으로 이동한다.

4. **맞춤 추천 설정 카드**
   - 제목: **`내 추천 기준`**
   - `관심 분야` → `취업·채용, 장학·지원금`
   - `관심 직무` → `데이터·기획`
   - `활동 목적` → `실무 경험 쌓기`
   - `참여 가능 시간` → `주말 · 주 4시간 이하`
   - 각 행 오른쪽 수정 화살표

5. **알림 설정 카드**
   - 제목: **`필요한 순간에 알려 드릴게요`**
   - `지원 마감 알림` 스위치 **켜짐**
   - 선택 칩: `3일 전 ✓` / `하루 전 ✓` / `당일 ✓`
   - 시간: `알림 받는 시간 09:00 ▾`
   - `내 준비 기한 알림` 스위치 **켜짐**
     - `내가 정한 기한 1시간 전`
   - `마감·자격 변경 알림` 스위치 **켜짐**
     - `원문에서 변경을 확인했을 때`
   - `새 맞춤 공고 요약` 스위치 **꺼짐**
   - `다음 회차 모집 알림` 스위치 **켜짐**

6. **스크롤 아래의 알림 세부 설정**
   - `방해 금지 시간 23:00–08:00`
   - `이 기기 알림 상태: 사용 중`
   - 버튼: `테스트 알림 보내기`
   - 알림 미리보기:
     - **`캠퍼스모아 · 지원 준비`**
     - `데이터 실무 프로젝트 D-3`
     - `이력서와 자기소개서를 준비해요.`

7. **기록과 서비스 설정**
   - `내 후기 2개`
   - `다음 회차 구독 2개`
   - `캘린더로 내보내기`
   - `화면 모드: 기기 설정 따름 ▾`
   - `의견 보내기`
   - `숨긴 사용자`
   - `이용약관 · 개인정보처리방침`
   - `로그아웃`, 하단에 작은 `회원 탈퇴`

8. **하단 탭**
   - `내 정보` 활성화.

**첫 화면에 보일 범위:** 프로필, 활동 요약, 추천 기준, 알림 카드의 지원 마감 설정까지.

#### 강조할 인터랙션

- 추천 설정을 바꾸면 `추천 기준을 저장했어요`를 표시한다.
- 알림을 처음 켤 때 받을 내용을 먼저 설명하고 기기 권한 요청으로 연결한다.
- 다른 기기에서만 활성화된 경우 `이 기기에서도 받기`를 보여 준다.
- 권한이 차단됐으면 스위치 아래에 `이 기기의 알림이 차단돼 있어요`와 설정 안내를 표시한다.
- 화면 모드는 `기기 설정 따름 / 라이트 / 다크` 중 선택한다.

## 4. 디자인 원칙과 비주얼 방향

### 디자인 원칙

1. **첫 화면에서 다음 행동이 보여야 한다.** 홈은 오늘의 준비와 추천, 상세는 마감·자격과 지원 준비, 내 일정은 다음 할 일을 우선한다.
2. **공고 정보의 순서를 통일한다.** 게시 학교 → 제목 → 마감 → 활동 조건 → 추천 이유 또는 준비 상태로 읽힌다.
3. **공식 정보와 개인 기록을 구분한다.** 공식 마감과 개인 준비 기한, 공식 준비물과 사용자가 추가한 할 일은 라벨로 구분한다.
4. **추천의 근거를 설명한다.** “나에게 딱 맞아요” 대신 “3학년 · 데이터 직무 관심으로 추천”처럼 판단 근거를 보여 준다.
5. **모르는 정보는 읽을 수 있는 상태로 표현한다.** `마감일 미확인`, `자격 확인 필요`를 명시하고 원문으로 연결한다.
6. **참새는 시작과 작은 성취에 사용한다.** 온보딩, 빈 화면, 제출 완료에 등장한다. 공고 목록에서는 정보가 중심이 된다.
7. **색과 함께 글자·아이콘으로 상태를 표시한다.** 마감, 완료, 선택을 색만으로 구분하지 않는다.

### 색상

### 타이포그래피

**Pretendard Variable을 유지한다.**

| 용도 | 크기 / 행간 | 굵기 |
|---|---|---|
| 온보딩·홈 큰 제목 | 28 / 36px | 700 |
| 화면 제목 | 24 / 32px | 700 |
| 상세 공고 제목 | 24 / 33px | 700 |
| 섹션 제목 | 20 / 28px | 700 |
| 공고 카드 제목 | 17 / 25px | 600 |
| 본문·버튼 | 16 / 24px | 400 / 600 |
| 정보·칩 | 14 / 20px | 500 |
| 출처·보조 라벨 | 12 / 18px | 400 / 500 |
| 활동 요약 숫자 | 24 / 30px | 700 |

- 카드 제목은 기본 2줄까지, 상세에서는 전체 제목을 보여 준다.
- 학교명과 D-day는 줄 중간에서 끊기지 않게 한다.
- 날짜와 진행 숫자는 숫자 폭을 일정하게 맞춘다.
- 핵심 마감과 자격 조건은 작은 보조 글씨로 축소하지 않는다.

### 카드·칩·버튼

- **공고 카드:** 폭 350px, 모서리 20px, 내부 여백 16px. 사진 없이 제목과 조건을 중심으로 구성한다.
- **추천 카드:** 제목 아래 한 줄 요약과 추천 이유를 포함한다.
- **탐색 카드:** 요약을 줄이고 마감·지역·대상을 강조한다.
- **준비 카드:** 진행 막대와 다음 할 일을 포함한다.
- **후기 카드:** 회차·작성자·인증 여부를 먼저 보여 준다.
- **그림자:** `0 2px 8px`, 검정 4% 수준. 구획은 여백과 얇은 선으로 구분한다.
- **필터 칩:** 높이 36px, 알약 모양. 선택 상태는 연한 파랑·파란 글씨·체크 표시.
- **학교 배지:** 모서리 6px, 연한 파랑. 게시 학교를 뜻한다.
- **상태 배지:** `준비 중`, `제출 완료`, `확인 필요` 등 글자를 함께 표시한다.
- **주요 버튼:** 높이 52px, 모서리 14px, 한 영역에 주요 행동 하나를 강조한다.
- **체크박스:** 시각 크기 24px, 터치 영역 44px. 완료한 항목도 내용을 읽을 수 있게 유지한다.

### 아이콘과 참새

- 기존 선 아이콘의 둥근 끝과 약 2px 선 두께를 이어 간다.
- 기본 아이콘은 24px, 정보 보조 아이콘은 16px.
- 하단 탭은 비활성 선형, 활성 채움형과 파란 글씨를 사용한다.
- 관심 표시는 현재의 별 아이콘을 유지한다.
- 참새는 크림색 몸과 갈색 날개를 유지하고, 작은 크기에서는 얼굴과 날개가 읽히도록 단순화한다.
- 빈 화면 예시: 참새와 작은 달력 아래 **`아직 준비 중인 지원이 없어요`**, 버튼 `첫 공고 찾아보기`.
- 제출 완료 예시: 작은 참새와 체크 아이콘, **`한 걸음 더 나아갔어요`**, 설명 `제출을 기록했어요. 결과 확인 일정도 추가할까요?`

### 함께 그릴 주요 상태

| 화면 | 추가로 표현할 상태와 실제 문구 |
|---|---|
| 온보딩 | 학교 검색 결과 없음: `찾는 학교가 없나요? 학교 추가를 요청해 주세요.` |
| 홈 | 추천 공고 없음: `지금 조건에 맞는 새 공고가 없어요. 활동 조건을 넓혀 볼까요?` |
| 탐색 | 필터 결과 없음: `주말 조건을 빼면 7개가 있어요.` |
| 상세 | 일정 미확인: `마감일을 확인하지 못했어요. 원문에서 확인해 주세요.` |

로딩은 최종 카드와 같은 형태의 스켈레톤으로 표현한다. 네트워크 오류에는 `다시 시도`를 제공하고, 저장된 화면을 보여 줄 때는 `마지막으로 확인한 정보 · 10.02 08:00`을 표시한다.
