# 설정 안내: 로그인·자동 수집·배포 켜기

코드는 모두 준비되어 있어요. 아래 세 가지는 본인 계정이 필요해서 직접 해 주셔야 해요.
순서대로 하면 되고, 1번만 해도 자동 수집이 시작돼요.

## 1. GitHub에 올리기 → 하루 1회 자동 수집

GitHub는 코드를 보관하는 사이트예요. 올려 두면 매일 오전 6시에 수집이 자동으로 실행돼요.

1. https://github.com 에 가입하고, 오른쪽 위 `+` → `New repository`로 빈 저장소를 만들어요.
2. 저장소 화면에 나오는 주소를 넣어 아래 명령을 실행해요.
   ```bash
   git remote add origin https://github.com/내아이디/저장소이름.git
   git push -u origin main
   ```
3. 저장소의 `Actions` 탭 → `정보 수집` → `Run workflow`를 눌러 한 번 직접 실행해 봐요.
   초록색 체크가 뜨면 성공이에요. 수집에 실패하면 GitHub가 메일로 알려 줘요.

## 2. Vercel로 배포하기 → 인터넷 주소 만들기

1. https://vercel.com 에 GitHub 계정으로 가입해요.
2. `Add New` → `Project`에서 위 저장소를 고르고 `Deploy`를 눌러요.
3. 끝나면 `https://....vercel.app` 주소가 생겨요. 이후에는 자동 수집으로 데이터가 바뀔 때마다
   알아서 다시 배포돼요.

## 3. Supabase로 로그인 켜기

지금은 "체험 모드"라서 관심 표시가 그 브라우저에만 저장돼요. 아래를 하면 소셜 로그인이 켜져요.

1. https://supabase.com 에 가입하고 `New project`를 만들어요.
2. 왼쪽 `SQL Editor`에 `supabase/schema.sql` 파일 내용을 붙여 넣고 `Run`을 눌러요.
3. `Project Settings` → `API`에서 `Project URL`과 `anon public` 키를 복사해요.
4. `.env.example`을 `.env.local`로 복사하고 두 값을 채워요. (내 컴퓨터용)
5. Vercel 프로젝트의 `Settings` → `Environment Variables`에도 같은 두 값을 넣고 다시 배포해요.
6. Supabase `Authentication` → `Providers`에서 Google과 Kakao를 켜요.
   각 화면의 안내대로 구글·카카오 개발자 사이트에서 키를 발급받아 넣어야 해요.
7. `Authentication` → `URL Configuration`의 `Site URL`에 Vercel 주소를 넣고,
   `Redirect URLs`에 `http://localhost:3000`도 추가해요.

## 4. (선택) AI 정보 추출 켜기

영대소식은 본문이 제각각이라 규칙만으로는 일정을 다 찾지 못해요. Codex CLI를 설치하고
로그인해 두면, 내 컴퓨터에서 `npm run collect`를 실행할 때 새 게시물을 AI가 읽고 보완해요.

```bash
npm install -g @openai/codex
```
