## 1. Vercel에 Supabase 키 넣기 → 배포된 사이트에서 로그인 켜기

`NEXT_PUBLIC_SUPABASE_URL`은 이미 넣어 두었어요. 키 하나만 추가하면 돼요.

1. Vercel → `tagi` 프로젝트 → `Settings` → `Environment Variables` → `Add Environment Variable`
2. Key: `NEXT_PUBLIC_SUPABASE_ANON_KEY`, Value: `.env.local`에 넣은 키와 같은 값 → `Save`
3. 화면에 뜨는 `Redeploy`를 누르거나, `Deployments`에서 최신 배포의 `...` → `Redeploy`

## 1-1. 후기 댓글 표 만들기 (완료, 다시 만들 때만)

반복 프로그램 상세 화면의 "후기·정보 나눔" 댓글은 Supabase의 `comments` 표에 저장돼요.

1. Supabase → `tagi` 프로젝트 → 왼쪽 `SQL Editor` → `New query`
2. `supabase/schema.sql` 파일에서 **`-- 반복 프로그램 후기·정보 나눔 댓글`** 줄부터 끝까지 복사해 붙여 넣기
3. `Run` → "Success"가 보이면 끝

댓글은 누구나 읽을 수 있고, 로그인한 사람만 쓸 수 있어요. 글쓴이는 "익명"으로 보이고, 자기 글만 지울 수 있어요.

## 1-2. 회원 탈퇴·댓글 신고·숨기기 켜기 (완료, 다시 만들 때만)


1. Supabase → `tagi` 프로젝트 → 왼쪽 `SQL Editor` → `New query`
2. `supabase/moderation.sql` 파일 내용을 **전부** 복사해 붙여 넣기
3. `Run` → "Success"가 보이면 끝

켜지는 것:
- **회원 탈퇴**: `내 정보` 화면 맨 아래. 계정과 학교 설정·관심 공고·댓글이 모두 지워져요
- **댓글 이용 규칙 동의**: 처음 댓글을 쓰기 전에 한 번 동의해요
- **신고**: 신고가 3건 쌓인 댓글은 자동으로 숨겨져요
- **숨기기**: 보고 싶지 않은 사람의 글을 나에게만 안 보이게 해요 (`내 정보`에서 다시 볼 수 있어요)
- 댓글을 누가 썼는지(계정 번호)가 밖으로 보이지 않게 바뀌어요

운영자가 할 일: 가끔 Supabase → `Table Editor` → `reports` 표에서 신고를 보고, 문제 있는 댓글은 `comments` 표에서 지워요.
잘못 숨겨진 댓글은 `comments` 표에서 `hidden`을 `false`로 바꾸면 다시 보여요.

문의처는 지금 GitHub 문의 게시판으로 되어 있어요. 이메일로 바꾸려면 `lib/policy.ts`의 `CONTACT`를 고치면 돼요.

## 1-6. 마감 알림·신고 알림 켜기 (GitHub에 비밀 값 2개 넣기) ← 할 일

매일 아침 9시에 GitHub Actions(`알림 보내기`)가
- 관심 공고 모집 마감 하루 전에, 프로필에서 "마감 알림"을 켠 사람의 기기로 알림을 보내고
- 새 댓글 신고·"정보가 틀렸어요" 신고가 있으면 GitHub에 **"신고 확인 필요" 이슈**를 만들어요. GitHub이 저장소 주인 메일(whgusals4@gmail.com)로 알려 줘요.

이 작업은 Supabase를 관리자 권한으로 읽어야 해서 비밀 값 2개가 필요해요. 넣기 전에는 아무것도 하지 않고 조용히 끝나요.

1. GitHub 저장소 → `Settings` → `Secrets and variables` → `Actions` → `New repository secret`
2. Name: `SUPABASE_SERVICE_ROLE_KEY`, Secret: Supabase → `tagi` → `Project Settings` → `API Keys`의 **service_role**(또는 secret) 키 → `Add secret`
   - 이 키는 모든 데이터를 읽고 쓸 수 있어요. GitHub Secrets에만 넣고, Vercel이나 `NEXT_PUBLIC_` 이름에는 절대 넣지 마세요.
3. 다시 `New repository secret` → Name: `VAPID_PRIVATE_KEY`, Secret: 내 컴퓨터 `.env.local` 파일의 `VAPID_PRIVATE_KEY=` 뒤의 값 → `Add secret`
   - 알림을 보내는 "도장" 비밀 키예요. 짝이 되는 공개 키는 `lib/push.ts`에 있어요. 비밀 키를 바꾸면 공개 키도 함께 바꿔야 해요.
4. 확인: `Actions` → `알림 보내기` → `Run workflow` → 초록 체크가 뜨고, 로그에 "마감 알림: 알림을 켠 사람 N명"이 보이면 성공

알림 받는 쪽: 프로필 → "마감 알림" 켜기 → 브라우저가 알림 허용을 물으면 `허용`.
아이폰은 Safari 공유 버튼 → "홈 화면에 추가"로 설치한 앱에서만 알림을 받을 수 있어요.

## 2. 영대소식 하루 2회 자동 수집 (내 컴퓨터)

영대소식(www.yu.ac.kr)은 해외 서버인 GitHub Actions에서 접속이 되지 않아요.
그래서 `config/schools.json`에서 `"localOnly": true`로 표시해 두었고, 내 컴퓨터에서 수집해 올려야 해요.

직접 한 번 실행하기:

```bash
powershell -ExecutionPolicy Bypass -File scripts/collect-local.ps1
```

매일 오후 1시·8시에 자동 실행 (Windows 작업 스케줄러 "tagi 정보 수집", 2026-10-02 등록 완료).
다시 등록할 때는 PowerShell에서:

```powershell
$action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-NoProfile -ExecutionPolicy Bypass -File `"C:\Users\jogain\Desktop\바이브 코딩\scripts\collect-local.ps1`""
$triggers = @((New-ScheduledTaskTrigger -Daily -At "13:00"), (New-ScheduledTaskTrigger -Daily -At "20:00"))
$settings = New-ScheduledTaskSettingsSet -StartWhenAvailable -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries
Register-ScheduledTask -TaskName "tagi 정보 수집" -Action $action -Trigger $triggers -Settings $settings -Force
```

- 정한 시간에 컴퓨터가 꺼져 있었으면, 다음에 켰을 때 바로 한 번 실행해요.
- 실행 기록은 `logs/collect-local.log`에 남아요.
- 등록을 지우려면: `schtasks /Delete /TN "tagi 정보 수집" /F`

## 3. AI 정보 추출 (Claude로 바꿈) ← 할 일: 로그인 한 번

내 컴퓨터에서 수집할 때 새 게시물을 **Claude**가 읽고 정리해요 (Codex 토큰을 아끼려고 바꿈).
Claude 앱에 들어 있는 Claude Code를 수집기가 찾아 써요. Claude 앱이 Microsoft Store 앱이라 실제 위치는 `%LOCALAPPDATA%\Packages\Claude_…\LocalCache\Roaming\Claude\claude-code\버전\claude.exe`예요.
이 프로그램은 앱과 로그인이 따로라서 **처음 한 번 로그인**해야 해요.

1. PowerShell을 열고 아래를 붙여 넣어 실행해요.

```powershell
& (Get-ChildItem "$env:LOCALAPPDATA\Packages\Claude_*\LocalCache\Roaming\Claude\claude-code\*\claude.exe" | Sort-Object LastWriteTime | Select-Object -Last 1).FullName
```

2. 화면이 뜨면 `/login`을 입력하고, 브라우저에서 Claude 계정으로 로그인해요.
3. 로그인이 끝나면 `/exit`로 닫아요.

로그인 전에는 AI 없이 규칙으로만 정리돼요 (수집은 계속돼요).
Codex로 되돌리고 싶으면 환경 변수 `AI_ENGINE=codex`를 두고 실행해요.

## 4. 검색 등록 (구글·네이버) ← 할 일

검색 결과에 사이트가 나오게 하려면, 검색엔진에 "이 사이트 주인이 나예요"라고 확인받고 사이트 지도(`sitemap.xml`)를 알려 줘야 해요.
사이트 지도는 이미 있어요: https://tagi-ten.vercel.app/sitemap.xml

**구글 서치 콘솔**
1. https://search.google.com/search-console 에 구글 계정으로 들어가요.
2. 속성 추가 → 오른쪽 **URL 접두어**에 `https://tagi-ten.vercel.app` 입력 → 계속
3. 확인 방법 중 **HTML 태그**를 열면 `<meta name="google-site-verification" content="abc123…" />`가 보여요.
   `content="` 뒤의 값(abc123…)만 복사해서 Claude에게 채팅으로 보내 주세요. 비밀번호가 아니라 공개되는 값이라 괜찮아요.
4. Claude가 `lib/policy.ts`의 `SITE_VERIFICATION.google`에 넣고 배포하면(1~2분), 서치 콘솔에서 **확인**을 눌러요.
5. 왼쪽 메뉴 **Sitemaps** → `sitemap.xml` 입력 → 제출

**네이버 서치어드바이저**
1. https://searchadvisor.naver.com 에 네이버 계정으로 들어가 → 웹마스터 도구 → 사이트 등록 → `https://tagi-ten.vercel.app`
2. 소유 확인에서 **HTML 태그**를 고르면 `<meta name="naver-site-verification" content="…" />`가 보여요. `content` 값만 Claude에게 보내 주세요.
3. 배포가 끝나면 **소유확인** → 요청 → **사이트맵 제출**에 `https://tagi-ten.vercel.app/sitemap.xml`

검색에 실제로 나오기까지는 며칠~몇 주 걸릴 수 있어요.

## 5. 도메인 연결 (campusmoa.kr, 가비아) ← 할 일

도메인은 인터넷 주소(예: campusmoa.kr)예요. 사는 것은 결제가 필요해서 직접 하시고, 연결 이후는 Claude가 도와요.

**① 가비아에서 사기**
1. https://www.gabia.com 에서 `campusmoa.kr` 검색 → 비어 있으면 장바구니 → 결제 (보통 1년 1~2만 원대)
2. 결제 후 1~2시간 안에 사용할 수 있어요.

**② Vercel에 주소 추가**
1. https://vercel.com → `tagi` 프로젝트 → `Settings` → `Domains` → `Add`
2. `campusmoa.kr` 입력 → 추천대로 `www.campusmoa.kr`도 함께 추가 (www로 들어와도 같은 사이트로)
3. Vercel이 "이 값을 DNS에 넣으세요"라며 **A 레코드**(값 예: `76.76.21.21`)와 **CNAME 레코드**(값 예: `cname.vercel-dns.com`)를 보여 줘요. 화면에 나온 값을 그대로 써요.

**③ 가비아 DNS에 값 넣기**
1. My가비아 → 이용 중인 서비스 → 도메인 → `campusmoa.kr`의 **관리** → **DNS 정보** → **DNS 설정**(레코드 수정)
2. 레코드 추가:
   - 타입 `A`, 호스트 `@`, 값 = Vercel의 A 레코드 값
   - 타입 `CNAME`, 호스트 `www`, 값 = Vercel의 CNAME 값 (끝에 점이 필요하다고 하면 `cname.vercel-dns.com.`)
3. 저장 → 10분~몇 시간 뒤 Vercel의 Domains 화면이 초록색 **Valid Configuration**으로 바뀌면 연결 끝. 주소창에 자물쇠(https)도 자동으로 붙어요.

**④ 연결된 뒤 Claude에게 "도메인 연결됐어"라고 말해 주세요.** Claude가 할 일:
- 사이트 주소(`lib/filter.ts`의 `SITE_URL`), 수집기 이름(`src/fetch.ts`), 알림 링크(`scripts/notify.ts`), 앱 데이터 주소(`mobile/src/data.tsx`), 문서의 주소를 새 주소로 바꾸고 배포
- 로그인 설정 바꾸기 안내 (직접 해야 해요, 각 1분):
  - Supabase → Authentication → URL Configuration: **Site URL**을 `https://campusmoa.kr`로, **Redirect URLs**에 `https://campusmoa.kr/**` 추가
  - Kakao Developers → 내 애플리케이션 → 플랫폼 → Web 사이트 도메인에 `https://campusmoa.kr` 추가
  - Google Cloud Console → OAuth 클라이언트 → 승인된 JavaScript 원본에 `https://campusmoa.kr` 추가 (리디렉션 URI는 Supabase 주소라 그대로)

예전 주소(tagi-ten.vercel.app)도 계속 열려요.

## 참고: 처음부터 다시 연결할 때

- **Supabase**: SQL Editor에서 `supabase/schema.sql` 실행 → `Authentication` → `Sign In / Providers`에서
  Google·Kakao 켜기 → `URL Configuration`의 Site URL에 배포 주소, Redirect URLs에 `http://localhost:3000` 추가
- **구글**: Google Cloud Console에서 OAuth 클라이언트(웹 애플리케이션)를 만들고, 승인된 리디렉션 URI에
  `https://<Supabase 프로젝트 id>.supabase.co/auth/v1/callback` 등록
- **카카오**: Kakao Developers → `앱` → `플랫폼 키` → REST API 키 화면에서 리다이렉트 URI 등록과
  클라이언트 시크릿 확인. `카카오 로그인` → `동의항목`에서 **카카오계정(이메일)을 "선택 동의"로 켜야 함**
  (Supabase가 이메일을 항상 요청해서, 꺼 두면 KOE205 오류가 남). Supabase의 `Allow users without an email`도 켜서
  이메일 제공을 거부한 사람도 로그인되게 함
- **내 컴퓨터**: `.env.example`을 `.env.local`로 복사하고 Supabase 주소와 키를 채움
