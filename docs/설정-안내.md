## 1. Vercel에 Supabase 키 넣기 → 배포된 사이트에서 로그인 켜기

`NEXT_PUBLIC_SUPABASE_URL`은 이미 넣어 두었어요. 키 하나만 추가하면 돼요.

1. Vercel → `tagi` 프로젝트 → `Settings` → `Environment Variables` → `Add Environment Variable`
2. Key: `NEXT_PUBLIC_SUPABASE_ANON_KEY`, Value: `.env.local`에 넣은 키와 같은 값 → `Save`
3. 화면에 뜨는 `Redeploy`를 누르거나, `Deployments`에서 최신 배포의 `...` → `Redeploy`

## 1-1. 후기 댓글 표 만들기 (완료, 다시 만들 때만)

반복 프로그램 상세 화면의 "후기·정보 나눔" 댓글은 Supabase의 `comments` 표에 저장돼요.

1. Supabase → `tagi` 프로젝트 → 왼쪽 `SQL Editor` → `New query`
2. `supabase/schema.sql` 파일에서 **`-- 반복 프로그램 후기·정보 나눔 댓글`** 줄부터 끝까지 복사해 붙여 넣기
3. `Run` → "Success"가 보이면 끝

댓글은 누구나 읽을 수 있고, 로그인한 사람만 쓸 수 있어요. 글쓴이는 "익명"으로 보이고, 자기 글만 지울 수 있어요.

## 1-2. 회원 탈퇴·댓글 신고·숨기기 켜기 (완료, 다시 만들 때만)


1. Supabase → `tagi` 프로젝트 → 왼쪽 `SQL Editor` → `New query`
2. `supabase/moderation.sql` 파일 내용을 **전부** 복사해 붙여 넣기
3. `Run` → "Success"가 보이면 끝

켜지는 것:
- **회원 탈퇴**: `내 정보` 화면 맨 아래. 계정과 학교 설정·관심 공고·댓글이 모두 지워져요
- **댓글 이용 규칙 동의**: 처음 댓글을 쓰기 전에 한 번 동의해요
- **신고**: 신고가 3건 쌓인 댓글은 자동으로 숨겨져요
- **숨기기**: 보고 싶지 않은 사람의 글을 나에게만 안 보이게 해요 (`내 정보`에서 다시 볼 수 있어요)
- 댓글을 누가 썼는지(계정 번호)가 밖으로 보이지 않게 바뀌어요

운영자가 할 일: 가끔 Supabase → `Table Editor` → `reports` 표에서 신고를 보고, 문제 있는 댓글은 `comments` 표에서 지워요.
잘못 숨겨진 댓글은 `comments` 표에서 `hidden`을 `false`로 바꾸면 다시 보여요.

문의처는 지금 GitHub 문의 게시판으로 되어 있어요. 이메일로 바꾸려면 `lib/policy.ts`의 `CONTACT`를 고치면 돼요.

## 2. 영대소식 하루 1회 자동 수집 (내 컴퓨터)

영대소식(www.yu.ac.kr)은 해외 서버인 GitHub Actions에서 접속이 되지 않아요.
그래서 `config/schools.json`에서 `"localOnly": true`로 표시해 두었고, 내 컴퓨터에서 수집해 올려야 해요.

직접 한 번 실행하기:

```bash
powershell -ExecutionPolicy Bypass -File scripts/collect-local.ps1
```

매일 오전 7시에 자동 실행되게 등록하기 (Windows 작업 스케줄러, 한 번만 실행):

```bash
schtasks /Create /SC DAILY /ST 07:00 /TN "tagi 정보 수집" /TR "powershell -NoProfile -ExecutionPolicy Bypass -File \"C:\Users\jogain\Desktop\바이브 코딩\scripts\collect-local.ps1\""
```

- 컴퓨터가 켜져 있을 때만 실행돼요. 실행 기록은 `logs/collect-local.log`에 남아요.
- 등록을 지우려면: `schtasks /Delete /TN "tagi 정보 수집" /F`

## 참고: 처음부터 다시 연결할 때

- **Supabase**: SQL Editor에서 `supabase/schema.sql` 실행 → `Authentication` → `Sign In / Providers`에서
  Google·Kakao 켜기 → `URL Configuration`의 Site URL에 배포 주소, Redirect URLs에 `http://localhost:3000` 추가
- **구글**: Google Cloud Console에서 OAuth 클라이언트(웹 애플리케이션)를 만들고, 승인된 리디렉션 URI에
  `https://<Supabase 프로젝트 id>.supabase.co/auth/v1/callback` 등록
- **카카오**: Kakao Developers → `앱` → `플랫폼 키` → REST API 키 화면에서 리다이렉트 URI 등록과
  클라이언트 시크릿 확인. `카카오 로그인` → `동의항목`에서 **카카오계정(이메일)을 "선택 동의"로 켜야 함**
  (Supabase가 이메일을 항상 요청해서, 꺼 두면 KOE205 오류가 남). Supabase의 `Allow users without an email`도 켜서
  이메일 제공을 거부한 사람도 로그인되게 함
- **내 컴퓨터**: `.env.example`을 `.env.local`로 복사하고 Supabase 주소와 키를 채움
