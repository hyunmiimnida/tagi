## 3. 브라우저 저장 목록 (4번)

**쿠키는 로그인 전 0개**로 측정했다(`document.cookie` 비어 있음, 응답에 `Set-Cookie` 없음). 모두 이 기기에만 있고 제공자는 캠퍼스모아이며 만료일은 없다(세션 저장소는 창을 닫으면 지워짐). 저장 위치는 항목마다 코드에서 다시 대조해야 한다.

| 이름 | 목적 | 필수 여부 |
|---|---|---|
| `visit-count`, `visit-counted` | 홈 화면 추가 안내를 두 번째 방문부터 | 편의 |
| `install-card-hidden`, `profile-nudge-hidden`, `dismissedNotice` | 닫은 안내를 다시 안 보이기 | 편의 |
| `lastListQuery`, `listLimit` | 목록으로 돌아올 때 필터와 보던 위치 | 편의 |
| `schoolId`, `favorites`, `profile`, `avatar` | 학교·관심 공고·선택값·캐릭터 | 기능 |
| `lastUserId` | 계정 바뀜 확인 | 기능 |
| `ownedWeapons`, `keyWallet` | 체험 모드 뽑기 | 기능 |
| Supabase 로그인 토큰 | 로그인 유지 | 필수. **이름·만료를 실제로 확인하지 못함**(로그인 시험 안 함) |
| 서비스 워커 캐시(`public/sw.js`) | 오프라인 때 마지막 화면 | 편의 |
